# Your Welcome Haven

Actúa como un diseñador de interfaces UI/UX de nivel experto. Quiero crear una app guía digital para mis huéspedes de airbnb. 

Pantalla INFO ÚTIL ya está diseñada y la adjunto

pantalla HOME que tienes que diseñar 

Quiero un diseño con una estética premium, minimalista y ultra limpio. Los títulos son Cormorant Garamond

Usa bordes muy redondeados (rounded-2xl), sombras sutiles, fuentes tipográficas modernas sin serifa y mucho espacio en blanco para que se sienta elegante y despejado.

Adjunto una imagen de diseño de referencia y una imagen que puedes usar (mesa blanca con pared rosa)
